Types of Data Collected

This Application processes personal data both autonomously via running framework scripts and through direct input panels.

Application-Specific Data Collected (Manual Item 1): We explicitly collect and process the following information provided directly by users during account creation and platform interaction: account emails, user-selected display names, profile biographies, custom profile avatars, user location preferences, text-based posts, and user-submitted comments.

Mode and Place of Processing the Data

Methods of Processing

The Data Controller processes User Data securely using modern encryption pipelines, applying strict structural controls and Row Level Security (RLS) policies to prevent unauthorized access, alteration, or absolute deletion of profile items.

Legal Basis of Processing

We process data to maintain service functionality, protect public safety within our community maps, and satisfy standard international compliance structures under GDPR and CCPA.

The Purposes of Processing

The data concerning the User is collected to allow the Owner to provide its Service, comply with its legal obligations, respond to enforcement requests, and protect its rights and interests.

Processing Purposes (Manual Item 3): Collected information is specifically utilized to power core platform personalization frameworks, calculate proximity-based map features (such as discovery heatmaps and route visualizations), and route targeted in-app or transactional notification pipelines.

Detailed Information on the Processing of Personal Data

Personal Data is collected for the following purposes and using the following explicit services:

Explicit Third-Party Sub-Processors (Manual Item 2 + Apple Fix): To provide core application functionality, user data is securely shared with and processed by the following explicit third-party services:

Roam uses identifiers and standard local storage tokens to manage encrypted sessions, account status tracking, and analytics contexts. For details on user configuration tools, please refer to our upcoming Cookie solution banner implementations (ROA-007).

We respect international privacy laws including the General Data Protection Regulation (GDPR) and the California Consumer Privacy Act (CCPA). Users retain the right to query their data profiles, restrict telemetry collection, or enforce absolute deletion.
